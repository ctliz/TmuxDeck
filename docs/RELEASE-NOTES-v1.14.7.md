## TmuxDeck v1.14.7 release notes

### Desktop notifications

- Notify when an Agent is waiting for a reply (`expectsReply`) and the main window is not focused.
- Keep one unread notice per pane until that reply is handled.
- Add a create-dialog setting to turn desktop notifications on or off. Existing configs default to on.
- Clicking a notification, or reopening TmuxDeck from the Dock with no visible window, opens the main window and highlights the waiting workspace.
